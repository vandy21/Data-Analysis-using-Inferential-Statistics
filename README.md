# 📊 End-to-End Inferential Statistics Analysis

### Probability, Hypothesis Testing & ANOVA Case Studies

---

## 📌 Project Overview

This project demonstrates the application of **inferential statistics techniques** to solve real-world analytical problems. It covers probability theory, normal distribution, hypothesis testing, and ANOVA to derive meaningful insights from multiple datasets.

The objective is to showcase how statistical methods can support **data-driven decision-making** across different domains such as sports analytics, manufacturing quality, and healthcare.

---

## 🧠 Key Concepts Covered

* Probability Theory
* Conditional Probability
* Normal Distribution & Z-score Analysis
* Hypothesis Testing (One-sample & Two-sample t-tests)
* ANOVA (One-way & Two-way)
* Interaction Effects Analysis
* Statistical Inference & Decision Making

---

## 📂 Project Structure

### 🔹 Problem 1: Sports Injury Analysis

* Analyzed relationship between player positions and injury occurrence
* Computed probabilities of injuries across different roles
* Applied conditional probability concepts

📊 Key Insight:

* Injury probability ≈ **61.7%**, indicating high injury risk among players

---

### 🔹 Problem 2: Manufacturing Quality Analysis

* Modeled breaking strength of gunny bags using **normal distribution**
* Applied **Z-score and CDF** to calculate probabilities

📊 Key Insights:

* ~11% bags fall below critical strength
* ~82% meet acceptable strength threshold

---

### 🔹 Problem 3: Hypothesis Testing (Zingaro Case Study)

* Tested whether unpolished stones meet required hardness level
* Performed:

  * One-sample t-test
  * Two-sample t-test

📊 Key Insights:

* Unpolished stones **fail to meet hardness requirement**
* Significant difference between polished & unpolished stones

---

### 🔹 Problem 4: Dental Implant Analysis (ANOVA)

* Evaluated impact of:

  * Dentists
  * Methods
  * Alloys
* Conducted:

  * One-way ANOVA
  * Two-way ANOVA
  * Interaction effect analysis

📊 Key Insights:

* Methods significantly impact hardness
* Strong interaction effect between dentist & method
* Alloy type influences variability
